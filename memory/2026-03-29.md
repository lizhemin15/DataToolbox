## Clawith 项目调研

### 发现
- Clawith 是基于 OpenClaw 的多 Agent 协作平台
- GitHub: https://github.com/dataelement/Clawith
- 官网: https://www.clawith.ai/

### 核心机制：Poll-Report-Send 轮询模式
外部 OpenClaw 实例通过 HTTP 轮询与 Clawith 通信：
- `GET /gateway/poll` - 获取待处理消息
- `POST /gateway/report` - 提交处理结果
- `POST /gateway/send-message` - 主动发送消息
- `POST /gateway/heartbeat` - 心跳保活

### 认证方式
每个外部 OpenClaw Agent 创建时生成 API Key：`oc-xxxxxxxx`

### 对比 AnyClaw
| 特性 | Clawith | AnyClaw |
|------|---------|---------|
| 连接方式 | HTTP 轮询 | WebSocket 长连接 |
| 消息存储 | GatewayMessage 表 | user_instance_messages 表 |
| 认证 | X-Api-Key | JWT Token |
| 复杂度 | 简单 | 中等 |
| 实时性 | 轮询延迟 | 实时推送 |

### 结论
如果要在 AnyClaw 实现类似功能，最简单的方案是：
1. 新增 `/gateway/poll`、`/gateway/report`、`/gateway/send-message` 接口
2. 新增 `gateway_messages` 表
3. 外部 OpenClaw 配置 API Key，定时轮询

## 拓扑图优化

### 问题
1. 手机和电脑端节点和连线位置错位
2. 手机端节点太大，看不清连线
3. 14个节点就很密集，无法容纳上百个节点

### 解决方案
1. **SVG 坐标系修复**：使用 `createSVGPoint + getScreenCTM().inverse()` 正确转换坐标
2. **知识图谱式重新设计**：
   - 节点改为小圆点（半径14px）
   - 力导向布局（Fruchterman-Reingold）
   - 支持缩放和平移
   - 添加 minimap
   - 连线更细（约1px）
3. **全屏功能**：
   - 添加全屏按钮（左上角，48×48px）
   - 自动锁定横屏方向
4. **节点名称**：
   - 在圆点下方常驻显示（SVG text）
   - 截断到14字符
