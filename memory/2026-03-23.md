## OpenClaw 架构对 DataToolbox 的启发

### 可借鉴的设计模式
1. **Gateway 控制平面** - 单一 WS 网关，所有客户端连接
2. **Registry + 声明式 Manifest** - 路由/方法/认证从散落代码迁到注册表
3. **通道抽象** - HTTP API/MCP tool/Webhook 共用执行内核
4. **Skills 系统** - 三层优先级，门控机制
5. **Session 管理** - 统一会话生命周期策略

### 落地优先级
- P0: 抽取路由注册、统一执行内核、增加 skills/ 目录
- P1: 插件接口 + manifest 校验、SessionStore、/ws/control 试点

## 本体论模块分析

### 当前功能
- 概念提取（从 schema 提取）
- 关系识别（LLM 推断）
- 图谱可视化（D3 2D + Three.js 3D）
- 语义查询（RAG 式 LLM 问答）

### 与斩首行动场景的差距
- 没有实例数据、时间维度、图算法、多层网络

### 加强建议
1. 时序分析 - events[] 模型，timeline UI
2. 多层关系网络 - layer（组织/资金/协作/通讯/地理）
3. 关键节点识别 - PageRank/Betweenness
4. 异常检测 - 统计规则 + 图结构异常
5. 多源融合 - 连接器 + 实体解析
6. 预测分析 - 马尔可夫转移 + 周期性分析
