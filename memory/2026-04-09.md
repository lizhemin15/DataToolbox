### 部署流程
1. `gh workflow run "Build and Release"` 触发编译
2. `gh run download <id> -D /tmp/datatoolbox-debug` 下载产物
3. 解压 → 备份数据 → 复制新二进制和前端 → 恢复数据 → 重启服务
4. 前端文件需要单独从 `/root/projects/DataToolbox/apps/data-ontology/` 复制到运行目录

### 注意事项
- 前端文件（index.html/script.js/style.css）更新后需要手动复制到运行目录
- `data-store.json` 在运行目录下，重启前要备份恢复
- 代码修改应该调度 Cursor，不要自己改
- GitHub Action Build Dev 只编译测试，Build and Release 才生成产物
- Release 需要手动创建：`gh release create v3.x.x`
