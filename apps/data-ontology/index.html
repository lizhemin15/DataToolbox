    🛡️ 安全配置
    
                    
    配置 MCP SQL 执行的安全限制，防止危险操作。
    
                    
    
                        
    
                            
                            
    
                                只读模式
                                仅允许 SELECT/SHOW/DESCRIBE/EXPLAIN 查询，禁止所有写操作
                            
    
                        
    
                        
    
                            
                            
    
                                阻止危险操作
                                阻止 DROP、DELETE、TRUNCATE、ALTER、GRANT 等危险 SQL 关键词
                            
    
                        
    
                        
    
                            
                            
                            额外要阻止的 SQL 关键词，每行一个
                        
    
                        
    
                            
                            
                            留空则不限制；填写后仅允许操作这些表
                        
    
                    
    
                
    
                
    
                    
    可用工具
    
                    
      
                        
    • list_databases — 列出已配置的数据库（不含密码）
      • 
                        
    • get_tables — 获取指定数据库的表列表及连接状态
      • 
                        
    • describe_table — 获取表的列结构（字段名、类型、键信息等）
      • 
                        
    • execute_sql — 在指定数据库上执行任意 SQL（SELECT 返回数据，写操作返回影响行数）
      • 
                        
    • list_apis — 列出已配置的接口
      • 
                        
    • get_api_detail — 获取接口完整详情（含 SQL、参数定义、描述）
      • 
                        
    • call_api — 调用已配置的接口，传入接口 ID 和参数执行并返回数据
      •

                                    • 首次提问需要使用 @数据库名

                                    • "@数据库 有哪些表？"

                                    • "@数据库 帮我创建一个查询用户的接口"
